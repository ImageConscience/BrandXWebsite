# Brand X Commerce

A simple website for lead collection.

## Setup

1. Install dependencies: `npm install`

2. Run the server: `npm start`

3. Open http://localhost:3000 in your browser.

Leads from the audit form are sent to Formspree (`https://formspree.io/f/mzdoypjj`),
not stored on the server.
